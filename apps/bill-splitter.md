# Bill Splitter

- Repo: [DangPham112000/bill-splitter](https://github.com/DangPham112000/bill-splitter). Live at `bills.dantepham.site` (`/opt/bill-splitter`) since 2026-10-25 (PR #4, DAN-84).
- Stack: pnpm monorepo; frontend React 19 + Vite + Tailwind + Apollo Client; backend Express + Apollo GraphQL + Mongoose; `shared/` holds money helpers used by both (VND by default, also THB, CNY, ...).
- Splits costs for a trip, project or party. Members join through a link without signing in; the app works out who pays whom with the fewest transfers.
- Sign-in: optional, with the shared Clerk app (live since 2026-10-25, DAN-84). The backend puts the Clerk user id in the GraphQL context as `clerkId` (null for anonymous members); no User table. Email, name and avatar come from `core.users` with a Clerk API fallback (`backend/src/coreUsers.ts`, DAN-93, bill-splitter #6); `me` returns `{ clerkId email name avatar }`. `Splitter.adminUserId` and `Member.userId` hold Clerk user ids, assigned once the create and join APIs exist (DAN-35, DAN-41). `CLERK_AUTHORIZED_PARTIES` is `${shared.prd.CLERK_AUTHORIZED_PARTIES}` (every ecosystem app, 2026-10-26).
- Secrets: Doppler `bill-splitter/prd` references `${shared.prd.CLERK_*}` and `${shared.prd.VPS_*}`; GitHub keeps only `DOPPLER_TOKEN`.
- Splitters (DAN-35, bill-splitter #7, 2026-10-26): GraphQL `createSplitter(input)` needs sign-in and makes the caller admin (`Splitter.adminUserId` = Clerk id, plus an admin `Member` linked by `userId`); input is name, type, coverEmoji, startDate/endDate as `YYYY-MM-DD`, currency (ISO 4217, VND default), hasInitialFund, adminName, memberNames. `updateSplitter` is admin only; `mySplitters` and `splitter(id)` return only splitters the caller administers or is linked to. `inviteToken` is shown to the admin only. No anonymous join yet (DAN-41).
- From Event Manager (DAN-96, bill-splitter #8, 2026-10-26): `createSplitter` also takes `description`, `eventManagerEventId` and `linkedMembers [{ name, clerkId }]` (each must be an attendee of that event; they become members linked to that account). `Query.eventManagerEvents` lists the user's events, read live from Event Manager (`EVENT_MANAGER_GRAPHQL_URL`, default `http://event-manager-backend:4000/graphql`). A splitter keeps `linkedEvent { app, id, url }`. `/new?event=<id>` opens the create form with that event picked.
- Target of the data-sharing flow Journei → Bill Splitter (DAN-94, can call `createSplitter` with the user's session token and `memberNames`; `linkedMembers` only accepts attendees of an Event Manager event for now).
- MongoDB: database `bill-splitter` on the shared `ecosystem-mongo` (user `bill-splitter`, DAN-90, bill-splitter #5), started empty. See [infra/mongo.md](../infra/mongo.md).
